# Personal Portfolio Website

A responsive portfolio project made with HTML5 and CSS3 only.

## Preview
Open `index.html` in a modern browser. No installation or build step is required.

## Customize
- Replace “Alex Morgan” and the biography/education placeholders with your information.
- Replace `hello@example.com` with an email address you want to share.
- Update the LinkedIn and GitHub links to your profiles.
- Replace the sample project descriptions and mockups with your own work.
- Update the page title and copyright name in `index.html`.

The Google Fonts link is optional; the page has system font fallbacks if it is unavailable.
